---
title: Клиент и сервер в управляемой форме

---

Код формы выполняется в двух местах: на **клиенте** (интерфейс) и на **сервере** (данные). Место задаёт директива компиляции.

| Директива | Где | Контекст формы |
|---|---|---|
| `&НаКлиенте` | клиент | есть |
| `&НаСервере` | сервер | передаётся на сервер и обратно |
| `&НаСервереБезКонтекста` | сервер | не передаётся |
| `&НаКлиентеНаСервереБезКонтекста` | оба | нет |

## Правила

- Каждый вызов сервера с клиента — сетевой обмен. Собирайте работу в **один** серверный вызов.
- Если реквизиты формы не нужны — `&НаСервереБезКонтекста`: передаётся меньше данных.
- На клиенте нет доступа к базе: запросы, `ПолучитьОбъект()` — только на сервере.

```bsl
&НаКлиенте
Процедура Рассчитать(Команда)
	Объект.Сумма = СуммаНаСервере(Объект.Ссылка);
КонецПроцедуры

&НаСервереБезКонтекста
Функция СуммаНаСервере(Ссылка)
	Возврат ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Ссылка, "СуммаДокумента");
КонецФункции
```
