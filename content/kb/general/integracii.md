## Способы интеграции

| Способ | Когда |
|---|---|
| HTTP-сервисы (входящие) и `HTTPСоединение` (исходящие) | REST-обмен, JSON |
| Веб-сервисы (SOAP) | обмен по WSDL-контракту |
| OData | стандартный REST-доступ к данным базы без написания своих сервисов |
| COM-соединение | обращение к другой базе 1С или приложению Windows |
| Файлы (XML, JSON) | пакетный обмен, когда нет онлайн-связи |
| Планы обмена | синхронизация баз 1С с регистрацией изменений |

## Вызов внешнего API: правила

1. **Вне транзакции.** Пока ждём ответа (таймаут может быть десятки секунд), транзакция держит блокировки.
2. **В `Попытка … Исключение`.** Сеть ненадёжна по определению.
3. **Ограниченные повторы.** Промежуточная неудача — в журнал как «Предупреждение», последняя — «Ошибка» и проброс исключения.
4. **Смотреть на код ответа.** 2xx — успех; 4xx — ошибка запроса (400 — данные, 401/403 — авторизация и права, 404 — нет ресурса), повтор того же запроса не поможет; 5xx — ошибка сервера, повтор может помочь.

```bsl
Функция Отправить(Данные)
	МаксимумПопыток = 3;
	Для НомерПопытки = 1 По МаксимумПопыток Цикл
		Попытка
			Соединение = Новый HTTPСоединение("api.example.com", , , , , 30);
			Запрос = Новый HTTPЗапрос("/api/data");
			Запрос.УстановитьТелоИзСтроки(Данные);
			Ответ = Соединение.ОтправитьДляОбработки(Запрос);
			Если Ответ.КодСостояния = 200 Тогда
				Возврат Истина;
			КонецЕсли;
			ВызватьИсключение СтрШаблон(НСтр("ru = 'Код ответа %1'"), Ответ.КодСостояния);
		Исключение
			ЗаписьЖурналаРегистрации(НСтр("ru = 'Интеграция.Отправка'"),
				?(НомерПопытки < МаксимумПопыток, УровеньЖурналаРегистрации.Предупреждение, УровеньЖурналаРегистрации.Ошибка), , ,
				ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
			Если НомерПопытки = МаксимумПопыток Тогда
				ВызватьИсключение;
			КонецЕсли;
		КонецПопытки;
	КонецЦикла;
	Возврат Ложь;
КонецФункции
```

## JSON

```bsl
// строка → данные
Чтение = Новый ЧтениеJSON;
Чтение.УстановитьСтроку(ТекстJSON);
Данные = ПрочитатьJSON(Чтение); // Структура; ПрочитатьJSON(Чтение, Истина) — Соответствие
Чтение.Закрыть();

// данные → строка
Запись = Новый ЗаписьJSON;
Запись.УстановитьСтроку();
ЗаписатьJSON(Запись, Данные);
ТекстJSON = Запись.Закрыть();
```

Структура подходит, когда ключи — допустимые идентификаторы; иначе читают в Соответствие.

## Планы обмена и РИБ

- **План обмена** описывает узлы и состав данных. При записи объекта из состава платформа регистрирует изменение для узлов — передаются только изменённые данные. После успешной передачи регистрацию снимают.
- **РИБ** (распределённая информационная база) — узлы с одной конфигурацией; от главного узла к подчинённым передаются и данные, и изменения конфигурации.
- **Обмен между разными конфигурациями** — через правила конвертации и универсальный формат.
- В конфигурациях на БСП обмен запускают через программный интерфейс `ОбменДаннымиСервер` (универсальный формат — `ОбменДаннымиXDTOСервер`), а не собирают сообщение обмена платформенными средствами в обход библиотеки — иначе не отработают регистрация изменений, протокол и разбор конфликтов.
