Главные правила из стандартов разработки 1С (its.1c.ru, раздел v8std). У каждого правила есть причина — если причина в конкретном месте не работает, отступление допустимо, но его поясняют комментарием.

## Именование

Имена — на русском, в ВерблюжьемРегистре.

| Что | Как | Пример |
|---|---|---|
| Переменная | существительное | `КоличествоСтрок`, `ДатаНачалаПериода` |
| Процедура | глагольная фраза | `ЗаполнитьТабличнуюЧасть` |
| Функция | существительное или вопрос | `ПолучитьСписокДокументов`, `ЭтоНовый` |
| Булево | утверждение | `ЕстьОшибки`, `РазрешеноРедактирование` |

Не называйте переменные именами глобального контекста (`Документы`, `Справочники`, `РегистрыСведений`, `Константы`, `ПараметрыСеанса`…) — затените менеджер.

## Структура модуля

Общий модуль — три стандартные области в таком порядке:

```bsl
#Область ПрограммныйИнтерфейс
// экспортные методы — публичный API
#КонецОбласти

#Область СлужебныйПрограммныйИнтерфейс
// экспортные методы для своей подсистемы
#КонецОбласти

#Область СлужебныеПроцедурыИФункции
// внутренняя реализация
#КонецОбласти
```

Модуль формы: `ОписаниеПеременных`, `ОбработчикиСобытийФормы`, `ОбработчикиСобытийЭлементовШапкиФормы`, `ОбработчикиСобытийЭлементовТаблицыФормы<Имя>`, `ОбработчикиКомандФормы`, `СлужебныеПроцедурыИФункции`. Области не вкладывают глубже двух уровней и не оставляют пустыми.

## Строки

- Без `Строка = Строка + …` в цикле: строки неизменяемы, каждая итерация копирует всё накопленное. Части — в массив, затем `СтрСоединить(Части, ", ")`.
- Подстановки — `СтрШаблон("Документ %1 от %2", Номер, Дата)` (до 10 параметров).
- Всё, что видит пользователь, — в `НСтр("ru = '…'")`, иначе текст не локализовать.

```bsl
ТекстСообщения = СтрШаблон(
	НСтр("ru = 'Остаток товара ""%1"" на складе: %2'"),
	Номенклатура, Остаток);
```

## Описание экспортных методов

У экспортной процедуры или функции обязателен комментарий: что делает, параметры с типами, возвращаемое значение. BSL динамически типизирован — комментарий единственный способ задокументировать контракт.

```bsl
// Возвращает курс валюты на дату.
//
// Параметры:
//  Валюта    - СправочникСсылка.Валюты - валюта.
//  ДатаКурса - Дата - дата курса.
//
// Возвращаемое значение:
//  Число - курс; 0, если курс не найден.
//
Функция КурсВалюты(Валюта, ДатаКурса) Экспорт
```

Комментарии внутри кода объясняют «зачем», а не пересказывают «что».

## Прочее

- **`Выполнить()` и `Вычислить()`** — только при крайней необходимости: это аналог eval, угроза безопасности и невидимый для анализа код.
- **Магические числа и строки** — в перечисления, константы, параметры.
- **Одна процедура — одна задача.** Больше ~100 строк — повод разбить.
- **Обращение через точку от ссылки в цикле** (`Стр.Номенклатура.ВидНоменклатуры`) — N обращений к базе. Данные берут одним запросом.
- **Бизнес-логика — в модуле объекта**, а не формы: так она сработает при записи из любого места.
- **Формы — через `ОткрытьФорму()`** с `ОписаниеОповещения`; `ПолучитьФорму()` — механизм обычного приложения.
