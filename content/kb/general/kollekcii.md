В BSL четыре коллекции, которые встречаются каждый день: **Массив**, **Структура**, **Соответствие**, **ТаблицаЗначений**.

| Коллекция | Доступ | Ключ | Когда использовать |
|---|---|---|---|
| Массив | по индексу с 0 | — | упорядоченный список |
| Структура | `Структура.Ключ` | строка-идентификатор | набор именованных полей, параметры методов |
| Соответствие | `Соответствие[Ключ]` | любое значение | словарь, быстрый поиск по ключу |
| ТаблицаЗначений | строки и колонки | — | табличные данные, группировка, сортировка |

## Массив

```bsl
М = Новый Массив;
М.Добавить(10);
М.Добавить(20);
Сообщить(М[0]);           // 10
Сообщить(М.Количество()); // 2
Индекс = М.Найти(20);     // 1 или Неопределено
```

`Найти()` перебирает массив целиком — на больших объёмах для поиска используйте Соответствие.

## Структура

```bsl
Сотрудник = Новый Структура("Имя, Возраст", "Артур", 25);
Сотрудник.Вставить("Отдел", "1С");
Если Сотрудник.Свойство("Отдел") Тогда
	Сообщить(Сотрудник.Отдел);
КонецЕсли;
```

Обращение к отсутствующему ключу через точку вызывает исключение — проверяйте `Свойство()`.

## Соответствие

```bsl
Цены = Новый Соответствие;
Цены.Вставить("Чай", 500);
Сообщить(Цены["Чай"]);    // 500
Сообщить(Цены["Кофе"]);   // Неопределено — без исключения
```

## ТаблицаЗначений

```bsl
ТЗ = Новый ТаблицаЗначений;
ТЗ.Колонки.Добавить("Товар");
ТЗ.Колонки.Добавить("Количество");
Стр = ТЗ.Добавить();
Стр.Товар = "Чай";
Стр.Количество = 2;
ТЗ.Свернуть("Товар", "Количество"); // группировка + сумма
ТЗ.Сортировать("Количество Убыв");
```
