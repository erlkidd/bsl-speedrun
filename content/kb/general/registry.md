## Какой регистр выбрать

| Регистр | Что хранит | Пример |
|---|---|---|
| Сведений | значения по измерениям (опционально по периоду) | курсы валют, цены |
| Накопления «Остатки» | приход/расход, есть остаток на дату | товары на складах, взаиморасчёты |
| Накопления «Обороты» | только движения за период | продажи, выручка |
| Бухгалтерии | проводки по плану счетов | регламентный учёт |
| Расчёта | записи расчёта с периодом действия | начисления зарплаты |

## Виртуальные таблицы

`Остатки`, `Обороты`, `ОстаткиИОбороты`, `СрезПоследних`, `СрезПервых` — данные считаются из таблиц движений и итогов.

```bsl
Запрос.Текст =
"ВЫБРАТЬ
|	Остатки.Номенклатура,
|	Остатки.КоличествоОстаток
|ИЗ
|	РегистрНакопления.ТоварыНаСкладах.Остатки(&Дата, Склад = &Склад) КАК Остатки";
```

Отбор по измерениям пишите **в параметрах** виртуальной таблицы, а не в `ГДЕ`: тогда фильтр применяется до расчёта.

## Схема проведения с контролем остатков

1. Очистить и сформировать движения (`Движения.ТоварыНаСкладах`).
2. Установить управляемую блокировку на нужные остатки (режим «Исключительный»).
3. Записать движения.
4. Проверить остатки запросом (минус → `Отказ = Истина` и сообщение).

Всё это выполняется в одной транзакции записи документа: если `Отказ`, движения откатятся.

## Отмена проведения

Платформа удаляет движения, у которых документ — регистратор. Сторнирование — прикладная логика, платформа сама его не делает.
