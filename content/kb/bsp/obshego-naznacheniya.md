Модуль `ОбщегоНазначения` (сервер) и `ОбщегоНазначенияКлиент` / `ОбщегоНазначенияКлиентСервер` — швейцарский нож БСП.

## Чтение реквизитов по ссылке

```bsl
// одно поле — один лёгкий запрос, без загрузки объекта
Организация = ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Документ, "Организация");

// несколько полей → Структура
Реквизиты = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Документ, "Организация, Дата, Номер");

// одно поле у многих ссылок → Соответствие Ссылка → Значение
Даты = ОбщегоНазначения.ЗначениеРеквизитаОбъектов(МассивДокументов, "Дата");
```

Не используйте `Ссылка.ПолучитьОбъект().Реквизит` ради одного поля: объект читается целиком, вместе с табличными частями.

## Сообщения пользователю

```bsl
ОбщегоНазначения.СообщитьПользователю(
	НСтр("ru = 'Не заполнена организация'"), Объект.Ссылка, "Организация", "Объект", Отказ);
```

Сообщение привязывается к полю формы, а `Отказ` выставляется в `Истина`.

## Прочее полезное

- `ОбщегоНазначения.ЭтоСсылка(Тип)` — является ли тип ссылочным.
- `ОбщегоНазначения.ОбъектМетаданныхПоПолномуИмени("Справочник.Номенклатура")`.
- `ОбщегоНазначенияКлиентСервер.ДополнитьМассив(Приемник, Источник, ТолькоУникальные)`.
- `ОбщегоНазначенияКлиентСервер.СвернутьМассив(Массив)` — убрать дубли.
- `ОбщегоНазначения.ХранилищеОбщихНастроекЗагрузить / Сохранить` — пользовательские настройки.
