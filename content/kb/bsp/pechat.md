Подсистема «Печать» строит печатные формы: команды печати, макеты, предварительный просмотр, отправку на принтер и почтой.

| Модуль | Для чего |
|---|---|
| `УправлениеПечатью` | программный интерфейс сервера |
| `УправлениеПечатьюКлиент` | клиент: выполнить команду печати, просмотр |
| `УправлениеПечатьюПереопределяемый` | вмешаться в собранный список команд или в процесс печати |

## 1. Объявить команду печати

Команды объявляют **в модуле менеджера** объекта процедурой `ДобавитьКомандыПечати(КомандыПечати)`. Библиотека сама соберёт их в форму объекта, форму списка и подменю.

Ключевые поля строки команды: `Идентификатор` (имя макета), `Представление` (текст в меню), `МенеджерПечати` (чья процедура `Печать` вызывается), `Обработчик` (для нестандартного поведения).

- Не добавляйте кнопку печати на форму вручную.
- Если обработчик не задан, идентификатор команды должен совпадать с именем макета — по нему библиотека ищет макет.

## 2. Сформировать печатную форму

```bsl
// Модуль менеджера документа
Процедура Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм,
	ОбъектыПечати, ПараметрыВывода) Экспорт

	Если УправлениеПечатью.НужноПечататьМакет(КоллекцияПечатныхФорм, "Накладная") Тогда
		УправлениеПечатью.ВывестиТабличныйДокументВКоллекцию(
			КоллекцияПечатныхФорм, "Накладная", "Накладная",
			СформироватьНакладную(МассивОбъектов, ОбъектыПечати));
	КонецЕсли;

КонецПроцедуры
```

- Сначала `НужноПечататьМакет` — пользователь мог снять галку с этой формы.
- Табличный документ кладут в коллекцию, а не возвращают: печатью управляет библиотека.
- `ОбъектыПечати` заполнять обязательно — по нему области документа связываются с объектами при пакетной печати.

## 3. Печать со своей кнопки на клиенте

```bsl
&НаКлиенте
Процедура НапечататьНакладную(Команда)
	Объекты = Новый Массив;
	Объекты.Добавить(Объект.Ссылка);
	УправлениеПечатьюКлиент.ВыполнитьКомандуПечати("Документ.РасходТовара", "Накладная", Объекты, ЭтаФорма);
КонецПроцедуры
```

С клиента — только модуль с суффиксом `Клиент`. `ВыполнитьКомандуПечатиНаПринтер` печатает без предварительного просмотра — удобно для массовой печати.
