## Агрегатные функции

| Функция | Что считает |
|---|---|
| `СУММА(Поле)` | сумму |
| `КОЛИЧЕСТВО(*)` | число строк группы |
| `КОЛИЧЕСТВО(Поле)` | число не-NULL значений |
| `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Поле)` | число разных значений |
| `МАКСИМУМ`, `МИНИМУМ` | наибольшее и наименьшее |
| `СРЕДНЕЕ` | среднее арифметическое |

Агрегаты пропускают NULL. Если в группе нечего складывать, `СУММА` вернёт NULL, а не 0.

## СГРУППИРОВАТЬ ПО

```query
ВЫБРАТЬ
    Подразделение,
    КОЛИЧЕСТВО(*) КАК Сотрудников,
    СУММА(Оклад) КАК Фонд,
    МАКСИМУМ(Оклад) КАК МаксОклад
ИЗ
    Справочник.Сотрудники
СГРУППИРОВАТЬ ПО
    Подразделение
```

**Правило:** каждое поле в `ВЫБРАТЬ` либо стоит в `СГРУППИРОВАТЬ ПО`, либо находится внутри агрегата. Иначе ошибка «поле не входит в группу».

Без `СГРУППИРОВАТЬ ПО` агрегат сворачивает всю выборку в одну строку.

Группировать можно по выражению — оно должно совпадать с выражением в списке полей:

```query
ВЫБРАТЬ
    МЕСЯЦ(Период) КАК Месяц,
    СУММА(Сумма) КАК Выручка,
    КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Регистратор) КАК Документов
ИЗ
    РегистрНакопления.Продажи
СГРУППИРОВАТЬ ПО
    МЕСЯЦ(Период)
УПОРЯДОЧИТЬ ПО
    Месяц
```

## ГДЕ и ИМЕЮЩИЕ

`ГДЕ` отбирает исходные строки **до** группировки, `ИМЕЮЩИЕ` — готовые группы **после**.

```query
ВЫБРАТЬ
    Контрагент,
    СУММА(Сумма) КАК Выручка
ИЗ
    РегистрНакопления.Продажи
ГДЕ
    Период >= ДАТАВРЕМЯ(2026, 3, 1)      // строки: только с марта
СГРУППИРОВАТЬ ПО
    Контрагент
ИМЕЮЩИЕ
    СУММА(Сумма) > 2000000               // группы: только крупные
```

В `ИМЕЮЩИЕ` агрегат пишется целиком — псевдоним колонки там недоступен. В `УПОРЯДОЧИТЬ ПО` псевдоним работает.

## ИТОГИ

`ИТОГИ` не сворачивают строки, а **добавляют** итоговые — по общему итогу и по каждой группировке:

```query
ВЫБРАТЬ
    Контрагент,
    Номенклатура,
    СУММА(Сумма) КАК Сумма
ИЗ
    РегистрНакопления.Продажи
СГРУППИРОВАТЬ ПО
    Контрагент,
    Номенклатура
ИТОГИ
    СУММА(Сумма)
ПО
    ОБЩИЕ,
    Контрагент
```

В результате: строка общего итога, затем по каждому контрагенту — строка итога и под ней детальные строки. В коде такой результат обходят по уровням: `Результат.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам)`.

## Типичные ошибки

- Агрегат в `ГДЕ` — нужен `ИМЕЮЩИЕ`.
- `КОЛИЧЕСТВО(*)` после левого соединения — считает и «пустые» строки; нужен `КОЛИЧЕСТВО(Правая.Поле)`.
- Сумма шапки документа после соединения со строками — посчитается по числу строк.
