Регистр сведений хранит значения в разрезе измерений: курс валюты, цену товара, штрихкод. Если регистр **периодический**, у каждой записи есть `Период`, и хранится вся история.

| Часть | Пример: ЦеныНоменклатуры |
|---|---|
| Измерения — «для чего» | Номенклатура, ВидЦены |
| Ресурсы — «что храним» | Цена |
| Период | с какой даты действует |

## Таблица записей

Обычная таблица регистра — все записи как есть. Нужна, когда интересна история:

```query
ВЫБРАТЬ
    Период,
    Цена
ИЗ
    РегистрСведений.ЦеныНоменклатуры
ГДЕ
    Номенклатура = ЗНАЧЕНИЕ(Справочник.Номенклатура.Ноутбук)
    И ВидЦены = ЗНАЧЕНИЕ(Справочник.ВидыЦен.Розничная)
УПОРЯДОЧИТЬ ПО
    Период
```

## СрезПоследних — «значение на дату»

`СрезПоследних(Период, Условие)` возвращает по каждому сочетанию измерений **одну** запись — самую позднюю не позже указанной даты.

```query
ВЫБРАТЬ
    Валюта,
    Курс,
    Период
ИЗ
    РегистрСведений.КурсыВалют.СрезПоследних(ДАТАВРЕМЯ(2026, 3, 20))
```

По доллару вернётся запись от 16.03, по остальным валютам — от 01.03.

- Первый параметр пуст — берутся самые последние записи.
- Второй параметр — условие по измерениям: `СрезПоследних(&Дата, ВидЦены = &ВидЦены)`.
- `СрезПервых(Период, Условие)` — зеркало: самая ранняя запись не раньше даты.

## Ошибка: дата в ГДЕ

```query
// НЕВЕРНО: срез без даты берёт июньские записи, а ГДЕ их отбрасывает
ВЫБРАТЬ Валюта, Курс
ИЗ РегистрСведений.КурсыВалют.СрезПоследних()
ГДЕ Период <= ДАТАВРЕМЯ(2026, 2, 15)
```

Результат — одна строка вместо четырёх. Дату передают параметром среза:

```query
ВЫБРАТЬ Валюта, Курс
ИЗ РегистрСведений.КурсыВалют.СрезПоследних(ДАТАВРЕМЯ(2026, 2, 15))
```

## Прайс-лист: срез в левом соединении

```query
ВЫБРАТЬ
    Ном.Наименование КАК Товар,
    ЕСТЬNULL(Цены.Цена, 0) КАК Цена
ИЗ
    Справочник.Номенклатура КАК Ном
        ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.ЦеныНоменклатуры.СрезПоследних(
                &Дата,
                ВидЦены = ЗНАЧЕНИЕ(Справочник.ВидыЦен.Розничная)) КАК Цены
        ПО Цены.Номенклатура = Ном.Ссылка
ГДЕ
    НЕ Ном.ЭтоГруппа
```

Отбор по виду цены стоит в **параметрах среза**. В `ГДЕ` он выбросил бы товары без цены.

## Сравнить два среза

Одну виртуальную таблицу можно взять дважды с разными датами:

```query
ВЫБРАТЬ
    Было.Номенклатура,
    Было.Цена КАК ЦенаБыло,
    Стало.Цена КАК ЦенаСтало
ИЗ
    РегистрСведений.ЦеныНоменклатуры.СрезПоследних(ДАТАВРЕМЯ(2026, 1, 1), ВидЦены = ЗНАЧЕНИЕ(Справочник.ВидыЦен.Розничная)) КАК Было
        ВНУТРЕННЕЕ СОЕДИНЕНИЕ РегистрСведений.ЦеныНоменклатуры.СрезПоследних(ДАТАВРЕМЯ(2026, 6, 1), ВидЦены = ЗНАЧЕНИЕ(Справочник.ВидыЦен.Розничная)) КАК Стало
        ПО Было.Номенклатура = Стало.Номенклатура
ГДЕ
    Было.Цена <> Стало.Цена
```

## Непериодический регистр

У него нет поля `Период` и нет срезов — на каждое сочетание измерений ровно одна запись. Читают саму таблицу:

```query
ВЫБРАТЬ Номенклатура
ИЗ РегистрСведений.ШтрихкодыНоменклатуры
ГДЕ Штрихкод = "4870001000028"
```

## Запомнить

- Срез — по одной записи на набор измерений; история — в таблице записей.
- Дата и отбор по измерениям — в параметрах виртуальной таблицы.
- Период среза включает указанный момент: запись ровно на дату попадёт в результат.
