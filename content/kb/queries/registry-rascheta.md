Регистр расчёта хранит результаты **периодических расчётов** — в первую очередь зарплату: начисления и удержания.

## Три вида времени

| Поле | Смысл | Пример |
|---|---|---|
| `ПериодРегистрации` | в каком расчётном месяце запись сделана | апрель |
| `ПериодДействияНачало` / `ПериодДействияКонец` | за какие даты начислено | 6–12 апреля (больничный) |
| Базовый период | за какой период брать базу для расчёта | прошлые 12 месяцев |

Отпуск за март, начисленный в апреле: период действия — март, период регистрации — апрель.

## Виды расчёта

`ПланВидовРасчета.Начисления` — особый справочник: оклад, премия, отпуск, больничный. Виды расчёта связаны между собой:

- **вытесняющие** — больничный вытесняет оклад на свои дни;
- **базовые** — премия считается от суммы оклада;
- **ведущие** — изменение одного требует перерасчёта другого.

## Основная таблица

```query
ВЫБРАТЬ
    Сотрудник,
    ВидРасчета,
    ПериодДействияНачало,
    ПериодДействияКонец,
    Результат,
    ОтработаноДней
ИЗ
    РегистрРасчета.Начисления
ГДЕ
    ПериодРегистрации = &Месяц
УПОРЯДОЧИТЬ ПО
    Сотрудник
```

Свод по сотрудникам с итогами:

```query
ВЫБРАТЬ
    Сотрудник,
    ВидРасчета,
    СУММА(Результат) КАК Результат
ИЗ
    РегистрРасчета.Начисления
ГДЕ
    ПериодРегистрации = &Месяц
СГРУППИРОВАТЬ ПО
    Сотрудник,
    ВидРасчета
ИТОГИ СУММА(Результат) ПО ОБЩИЕ, Сотрудник
```

## Сторно

Перерасчёт прошлого периода не правит старую запись, а добавляет пару: запись с признаком `Сторно` и обратным знаком и новую запись с верным результатом.

```query
ВЫБРАТЬ
    ПериодРегистрации,
    Сотрудник,
    ВидРасчета,
    Результат,
    Сторно
ИЗ
    РегистрРасчета.Начисления
ГДЕ
    ВидРасчета = ЗНАЧЕНИЕ(ПланВидовРасчета.Начисления.Премия)
УПОРЯДОЧИТЬ ПО
    ПериодРегистрации
```

В учебной базе мартовская премия одного из менеджеров пересчитана в апреле: видно сторно на −84 000 и новую запись на 90 000.

## Период действия

Длительность отсутствия считается по периоду действия:

```query
ВЫБРАТЬ
    Сотрудник,
    ВидРасчета,
    РАЗНОСТЬДАТ(ПериодДействияНачало, ПериодДействияКонец, ДЕНЬ) + 1 КАК Дней
ИЗ
    РегистрРасчета.Начисления
ГДЕ
    ВидРасчета В (
        ЗНАЧЕНИЕ(ПланВидовРасчета.Начисления.Отпуск),
        ЗНАЧЕНИЕ(ПланВидовРасчета.Начисления.Больничный))
```

## Виртуальные таблицы

| Таблица | Назначение |
|---|---|
| `ФактическийПериодДействия` | реальные интервалы действия записей с учётом вытеснения |
| `ДанныеГрафика` | норма времени по графику в периоде действия |
| `База<Имя>` | база для расчёта по базовым видам расчёта |
| `Перерасчет<Имя>` | записи, требующие перерасчёта |

> В тренажёре из них реализована только `ФактическийПериодДействия(Условие)` в упрощённом виде: записи без сторно. Остальные таблицы требуют графиков и настройки связей видов расчёта — это тема отдельного курса по ЗУП.
