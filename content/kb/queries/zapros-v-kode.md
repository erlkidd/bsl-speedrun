## Базовый шаблон

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|	Остатки.Номенклатура КАК Номенклатура,
|	Остатки.КоличествоОстаток КАК Количество
|ИЗ
|	РегистрНакопления.ТоварыНаСкладах.Остатки(&Дата, Склад = &Склад) КАК Остатки";
Запрос.УстановитьПараметр("Дата", КонецДня(Дата));
Запрос.УстановитьПараметр("Склад", Склад);

Выборка = Запрос.Выполнить().Выбрать();
Пока Выборка.Следующий() Цикл
	Сообщить(СтрШаблон("%1: %2", Выборка.Номенклатура, Выборка.Количество));
КонецЦикла;
```

Запрос выполняется только **на сервере**.

## Параметры, а не склейка строк

```bsl
// ПЛОХО: значение вклеено в текст
Запрос.Текст = "ВЫБРАТЬ Ссылка ИЗ Справочник.Контрагенты ГДЕ ИНН = """ + ИНН + """";

// ХОРОШО
Запрос.Текст = "ВЫБРАТЬ Ссылка ИЗ Справочник.Контрагенты ГДЕ ИНН = &ИНН";
Запрос.УстановитьПараметр("ИНН", ИНН);
```

Склейка ломается на кавычках и датах, открывает дорогу подмене текста запроса и не даёт СУБД повторно использовать план. Собирать текстом можно только **имена** таблиц и полей, взятые из метаданных.

Список значений — параметром-массивом: `ГДЕ Ссылка В (&Ссылки)`.

## Что делать с результатом

| Способ | Когда |
|---|---|
| `Результат.Пустой()` | только узнать, есть ли строки |
| `Результат.Выбрать()` | последовательный обход, экономит память |
| `Результат.Выгрузить()` | нужна таблица значений: поиск, передача дальше |
| `Результат.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам)` | результат с `ИТОГИ` |

Одно значение:

```bsl
Выборка = Запрос.Выполнить().Выбрать();
Если Выборка.Следующий() Тогда
	Курс = Выборка.Курс;
КонецЕсли;
```

## Не выполняй запрос в цикле

```bsl
// ПЛОХО: запрос на каждую строку
Для Каждого Строка Из Товары Цикл
	Строка.Цена = ЦенаТовара(Строка.Номенклатура);   // внутри — запрос
КонецЦикла;

// ХОРОШО: один запрос, потом соответствие
Запрос.Текст =
"ВЫБРАТЬ
|	Цены.Номенклатура КАК Номенклатура,
|	Цены.Цена КАК Цена
|ИЗ
|	РегистрСведений.ЦеныНоменклатуры.СрезПоследних(&Дата, Номенклатура В (&Товары)) КАК Цены";
Запрос.УстановитьПараметр("Товары", Товары.ВыгрузитьКолонку("Номенклатура"));

Цены = Новый Соответствие;
Выборка = Запрос.Выполнить().Выбрать();
Пока Выборка.Следующий() Цикл
	Цены.Вставить(Выборка.Номенклатура, Выборка.Цена);
КонецЦикла;
```

То же относится к обращению через точку от ссылки в цикле: `Строка.Номенклатура.Артикул` читает объект из базы на каждой итерации.

## Пакет запросов

```bsl
Результаты = Запрос.ВыполнитьПакет();
Итоги = Результаты[1].Выгрузить();   // результат второго запроса пакета
```

`Выполнить()` возвращает результат только последнего запроса, `ВыполнитьПакет()` — массив результатов по порядку.

## Таблица значений как источник

```bsl
Запрос.Текст =
"ВЫБРАТЬ
|	Данные.Штрихкод КАК Штрихкод,
|	Данные.Количество КАК Количество
|ПОМЕСТИТЬ втДанные
|ИЗ
|	&Данные КАК Данные
|;
|ВЫБРАТЬ
|	Штрихкоды.Номенклатура КАК Номенклатура,
|	втДанные.Количество КАК Количество
|ИЗ
|	втДанные КАК втДанные
|		ВНУТРЕННЕЕ СОЕДИНЕНИЕ РегистрСведений.ШтрихкодыНоменклатуры КАК Штрихкоды
|		ПО втДанные.Штрихкод = Штрихкоды.Штрихкод";
Запрос.УстановитьПараметр("Данные", ТаблицаДанных);   // колонки должны быть типизированы
```

## Оформление текста

- Каждый раздел и каждое поле — с новой строки, ключевые слова заглавными.
- Всем полям и таблицам — осмысленные псевдонимы через `КАК`.
- `РАЗРЕШЕННЫЕ` — если запрос выполняется от имени пользователя с ограничениями на уровне записей.
