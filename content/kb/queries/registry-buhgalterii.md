Регистр бухгалтерии хранит **проводки**: одна сумма одновременно в дебет одного счёта и в кредит другого. Аналитика счёта — **субконто** (контрагент, номенклатура, склад…).

| Объект | Имя в запросе |
|---|---|
| Проводки | `РегистрБухгалтерии.Хозрасчетный` |
| План счетов | `ПланСчетов.Хозрасчетный` |
| Виды субконто | `ПланВидовХарактеристик.ВидыСубконтоХозрасчетные` |

## Журнал проводок

```query
ВЫБРАТЬ
    Период,
    СчетДт,
    СубконтоДт1,
    СчетКт,
    СубконтоКт1,
    Сумма,
    Содержание
ИЗ
    РегистрБухгалтерии.Хозрасчетный
ГДЕ
    Регистратор ССЫЛКА Документ.РеализацияТоваров
УПОРЯДОЧИТЬ ПО
    Период
```

Сложить `Сумма` по этой таблице и получить остаток счёта нельзя: сумма относится сразу к двум счетам разными сторонами. Развёртку делают виртуальные таблицы.

## Остатки

`Остатки(Период, УсловиеСчета, Субконто, Условие)`.

```query
ВЫБРАТЬ
    Счет,
    Счет.Наименование КАК Название,
    СуммаОстатокДт,
    СуммаОстатокКт
ИЗ
    РегистрБухгалтерии.Хозрасчетный.Остатки()
УПОРЯДОЧИТЬ ПО
    Счет
```

Сальдо в разрезе аналитики — добавь субконто и условие счёта:

```query
ВЫБРАТЬ
    Субконто1 КАК Покупатель,
    СуммаОстаток КАК Долг
ИЗ
    РегистрБухгалтерии.Хозрасчетный.Остатки(,
        Счет = ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыСПокупателями))
```

- `СуммаОстаток` — сальдо со знаком (дебет минус кредит);
- `СуммаОстатокДт`, `СуммаОстатокКт` — дебетовое и кредитовое сальдо по отдельности;
- для количественных счетов — `КоличествоОстаток`.

## Обороты

`Обороты(НачалоПериода, КонецПериода, Периодичность, УсловиеСчета, Субконто, Условие, УсловиеКорСчета, КорСубконто)`.

```query
ВЫБРАТЬ
    Счет,
    СуммаОборотДт,
    СуммаОборотКт
ИЗ
    РегистрБухгалтерии.Хозрасчетный.Обороты(&Начало, &Конец)
УПОРЯДОЧИТЬ ПО
    Счет
```

Счёт-группа вместе с субсчетами — через иерархию:

```query
ВЫБРАТЬ
    Счет,
    СуммаОборотДт,
    СуммаОборотКт
ИЗ
    РегистрБухгалтерии.Хозрасчетный.Обороты(, , ,
        Счет В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.Продажи)))
```

## ОборотыДтКт — корреспонденция

`ОборотыДтКт(НачалоПериода, КонецПериода, Периодичность, УсловиеСчетаДт, СубконтоДт, УсловиеСчетаКт, СубконтоКт, Условие)`.

```query
ВЫБРАТЬ
    СчетДт,
    СчетКт,
    СуммаОборот
ИЗ
    РегистрБухгалтерии.Хозрасчетный.ОборотыДтКт()
УПОРЯДОЧИТЬ ПО
    СчетДт, СчетКт
```

## Ловушки параметров

- Условие по счёту — **отдельный** параметр (`УсловиеСчета`), а не часть общего условия. У `Остатки` он второй, у `Обороты` — четвёртый. Сдвинешь позицию — отбор молча не сработает.
- В параметр `Субконто` передают **виды** субконто (что считать Субконто1, Субконто2), а не значения. Отбор по значению — в `Условие`: `Субконто1 = &Контрагент`.
- Синтакс-помощник платформы параметры условий счёта часто не показывает — сверяйся с документацией.

## Суффиксы ресурсов

| Таблица | Поля для ресурса «Сумма» |
|---|---|
| Остатки | `СуммаОстаток`, `СуммаОстатокДт`, `СуммаОстатокКт`, `СуммаРазвернутыйОстатокДт/Кт` |
| Обороты | `СуммаОборот`, `СуммаОборотДт`, `СуммаОборотКт` |
| ОстаткиИОбороты | `СуммаНачальныйОстаток(Дт/Кт)`, `СуммаОборот(Дт/Кт)`, `СуммаКонечныйОстаток(Дт/Кт)` |
| ОборотыДтКт | `СуммаОборот`, `КоличествоОборотДт`, `КоличествоОборотКт` |

> В тренажёре регистр упрощён: одна организация, не больше двух субконто на счёт, параметр «Субконто» принимается, но порядок субконто берётся из настроек счёта.
