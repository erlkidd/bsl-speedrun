Запрос — это описание того, **какие данные нужны**, а не как их доставать. Все примеры ниже выполняются в [консоли запросов](/queries) на учебной базе.

## Скелет запроса

Разделы идут в строго определённом порядке, обязательный только первый:

```query
ВЫБРАТЬ РАЗЛИЧНЫЕ ПЕРВЫЕ 10
    Наименование,
    Город
ИЗ
    Справочник.Контрагенты
ГДЕ
    НЕ ЭтоПоставщик
УПОРЯДОЧИТЬ ПО
    Наименование
```

| Раздел | Что делает |
|---|---|
| `ВЫБРАТЬ` | какие колонки вернуть; `РАЗЛИЧНЫЕ` — без повторов, `ПЕРВЫЕ N` — не больше N строк |
| `ИЗ` | откуда: таблицы и соединения |
| `ГДЕ` | отбор строк |
| `СГРУППИРОВАТЬ ПО` / `ИМЕЮЩИЕ` | свёртка и отбор групп |
| `УПОРЯДОЧИТЬ ПО` | сортировка, `ВОЗР` (по умолчанию) или `УБЫВ` |

## Имена таблиц

| Объект | Имя в запросе |
|---|---|
| Справочник | `Справочник.Номенклатура` |
| Документ | `Документ.РеализацияТоваров` |
| Табличная часть | `Документ.РеализацияТоваров.Товары` |
| Регистр сведений | `РегистрСведений.КурсыВалют` |
| Регистр накопления | `РегистрНакопления.ТоварыНаСкладах` |
| Регистр бухгалтерии | `РегистрБухгалтерии.Хозрасчетный` |
| Регистр расчёта | `РегистрРасчета.Начисления` |

Имена объектов и полей не угадывают — их смотрят в конфигурации (в консоли — дерево метаданных слева).

## Псевдонимы

`КАК` задаёт имя колонке или таблице. Слово `КАК` можно опустить — поэтому **пропущенная запятая не даёт ошибки**, а превращает следующее слово в псевдоним:

```query
ВЫБРАТЬ
    Наименование Город   // одна колонка с именем «Город»!
ИЗ
    Справочник.Контрагенты
```

## Условия

| Запись | Смысл |
|---|---|
| `=`, `<>`, `<`, `>`, `<=`, `>=` | сравнения |
| `И`, `ИЛИ`, `НЕ` | логика; приоритет: НЕ → И → ИЛИ |
| `МЕЖДУ А И Б` | диапазон, границы включены |
| `В (1, 2, 3)`, `В (&Список)` | вхождение в список |
| `В ИЕРАРХИИ (&Группа)` | группа и всё, что в ней на любом уровне |
| `ПОДОБНО "Чай%"` | шаблон: `%` — любые символы, `_` — один |
| `ЕСТЬ NULL` | проверка на NULL (через `=` не работает) |
| `ССЫЛКА Документ.Х` | проверка типа ссылки |

```query
ВЫБРАТЬ
    Наименование
ИЗ
    Справочник.Номенклатура
ГДЕ
    Ссылка В ИЕРАРХИИ (ЗНАЧЕНИЕ(Справочник.Номенклатура.Электроника))
    И НЕ ЭтоГруппа
    И НЕ ПометкаУдаления
```

## Значения в тексте запроса

- число: `100`, `3.5`; строка: `"Алматы"`; булево: `ИСТИНА`, `ЛОЖЬ`;
- дата: `ДАТАВРЕМЯ(2026, 3, 31)`;
- перечисление, предопределённый элемент, пустая ссылка: `ЗНАЧЕНИЕ(Перечисление.ВидыНоменклатуры.Товар)`, `ЗНАЧЕНИЕ(Справочник.Склады.ПустаяСсылка)`;
- всё, что приходит снаружи, — **параметр**: `&Дата`, `&Склад`.

## Обращение через точку

От ссылочного поля можно «шагнуть» к полям объекта, на который оно ссылается. Платформа сама добавит соединение:

```query
ВЫБРАТЬ
    Номер,
    Контрагент.Наименование КАК Покупатель,
    Контрагент.Город КАК Город
ИЗ
    Документ.РеализацияТоваров
ГДЕ
    Проведен
```

Осторожно с полями **составного типа** (например, `Регистратор`): точка от них присоединяет все возможные таблицы. Сужай тип: `ВЫРАЗИТЬ(Регистратор КАК Документ.РеализацияТоваров).Номер`.
