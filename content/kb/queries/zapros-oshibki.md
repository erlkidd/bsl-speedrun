Шпаргалка «симптом → причина → лечение». Почти все пункты можно воспроизвести в [консоли](/queries).

## Результат неверный

| Симптом | Причина | Лечение |
|---|---|---|
| Строк намного больше, чем ждал | таблицы через запятую без условия или соединение по неполному ключу | добавить условие `ПО` |
| Суммы удвоились | к шапке документа присоединена таблица с несколькими строками | считать суммы до соединения (временная таблица) |
| Пропали строки левой таблицы | условие по правой таблице стоит в `ГДЕ` | перенести в `ПО` или в параметры виртуальной таблицы |
| Вместо числа пусто | арифметика с NULL после левого соединения | `ЕСТЬNULL(Поле, 0)` |
| Срез на дату вернул не все строки | дата стоит в `ГДЕ`, а не в параметре среза | `СрезПоследних(&Дата, …)` |
| Одна колонка вместо двух | пропущена запятая, второе поле стало псевдонимом | поставить запятую |
| `ПОДОБНО` ничего не находит | в шаблоне нет `%` | `ПОДОБНО "Чай%"` |
| `Поле = NULL` всегда ложно | с NULL нельзя сравнивать | `Поле ЕСТЬ NULL` |
| У «пустой» группы количество 1 | `КОЛИЧЕСТВО(*)` считает строку с NULL | `КОЛИЧЕСТВО(Правая.Поле)` |
| Отбор по счёту не работает | условие попало не в тот позиционный параметр | сверить порядок параметров виртуальной таблицы |

## Запрос падает

| Сообщение | Что не так |
|---|---|
| Поле не входит в группу | поле в `ВЫБРАТЬ` не указано в `СГРУППИРОВАТЬ ПО` и не под агрегатом |
| Агрегатная функция недопустима | агрегат в `ГДЕ` — нужно `ИМЕЮЩИЕ` |
| Неоднозначное поле | имя есть в нескольких таблицах — укажи псевдоним таблицы |
| Таблица не найдена | опечатка в имени или забыт `ПОМЕСТИТЬ` у временной таблицы |
| Поле не найдено | в виртуальной таблице ресурс называется с суффиксом: `КоличествоОстаток` |
| Разное число полей в объединении | запросы под `ОБЪЕДИНИТЬ` должны возвращать одинаковое число колонок |
| Не задан параметр | в тексте есть `&Имя`, а `УстановитьПараметр` не вызван |

## Запрос работает медленно

1. **Запрос в цикле.** Один запрос с параметром-массивом или временной таблицей.
2. **Отбор виртуальной таблицы в `ГДЕ`.** Перенеси в параметры.
3. **Соединение с вложенным запросом.** Вынеси во временную таблицу, при необходимости с `ИНДЕКСИРОВАТЬ ПО`.
4. **Точка от поля составного типа.** `ВЫРАЗИТЬ(Регистратор КАК Документ.Х).Поле`.
5. **`ИЛИ` в условии по индексируемым полям.** Замени на `В (…)` или раздели на `ОБЪЕДИНИТЬ ВСЕ`.
6. **Функция над полем в `ГДЕ`.** `ГОД(Дата) = 2026` → `Дата МЕЖДУ &Начало И &Конец`.
7. **`ОБЪЕДИНИТЬ` там, где хватит `ОБЪЕДИНИТЬ ВСЕ`.**
8. **`ВЫБРАТЬ *` и лишние поля.** Выбирай только то, что используешь.
9. **`РАЗЛИЧНЫЕ` «на всякий случай».** Найди источник дублей.
10. **Нет ограничения строк.** Для списков и поиска — `ПЕРВЫЕ N`.

## Проверочный список перед сдачей

- [ ] Все внешние значения — параметры.
- [ ] У всех полей и таблиц понятные псевдонимы.
- [ ] Отборы регистров — в параметрах виртуальных таблиц.
- [ ] После левых соединений нет условий на правую таблицу в `ГДЕ` и стоит `ЕСТЬNULL`.
- [ ] Нет вложенных запросов в соединениях.
- [ ] Запрос не вызывается в цикле.
- [ ] Результат проверен на строках без пары и на пустой выборке.
