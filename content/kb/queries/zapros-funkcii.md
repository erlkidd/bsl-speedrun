## ВЫБОР — условие внутри выражения

```query
ВЫБРАТЬ
    Номер,
    СуммаДокумента,
    ВЫБОР
        КОГДА СуммаДокумента >= 1500000 ТОГДА "Крупная"
        КОГДА СуммаДокумента >= 500000 ТОГДА "Средняя"
        ИНАЧЕ "Мелкая"
    КОНЕЦ КАК Категория
ИЗ
    Документ.РеализацияТоваров
ГДЕ
    Проведен
```

Ветки проверяются сверху вниз, срабатывает первая истинная. Без `ИНАЧЕ` несовпавшие строки получат NULL.

`ВЫБОР` удобно сочетать с агрегатом — «сумма только по условию»:

```query
ВЫБРАТЬ
    Номенклатура,
    СУММА(ВЫБОР КОГДА ВидДвижения = ЗНАЧЕНИЕ(ВидДвиженияНакопления.Приход) ТОГДА Количество ИНАЧЕ 0 КОНЕЦ) КАК Приход,
    СУММА(ВЫБОР КОГДА ВидДвижения = ЗНАЧЕНИЕ(ВидДвиженияНакопления.Расход) ТОГДА Количество ИНАЧЕ 0 КОНЕЦ) КАК Расход
ИЗ
    РегистрНакопления.ТоварыНаСкладах
СГРУППИРОВАТЬ ПО
    Номенклатура
```

## NULL

NULL — «значения нет». Появляется после внешних соединений и в агрегатах по пустому набору.

- Любая арифметика и любое сравнение с NULL дают NULL: `100 + NULL`, `NULL = NULL`, `NULL > 0`.
- В `ГДЕ` проходит только истина, поэтому строка с NULL в условии отбрасывается.
- Проверка: `Поле ЕСТЬ NULL`, `Поле ЕСТЬ НЕ NULL`.
- Замена: `ЕСТЬNULL(Поле, 0)`.

NULL — не то же самое, что `Неопределено`, пустая ссылка или 0.

## Функции дат

| Функция | Пример | Результат |
|---|---|---|
| `ДАТАВРЕМЯ(г, м, д[, ч, мин, с])` | `ДАТАВРЕМЯ(2026, 3, 31)` | литерал даты |
| `ГОД`, `КВАРТАЛ`, `МЕСЯЦ`, `ДЕНЬ`, `ЧАС`, `МИНУТА` | `МЕСЯЦ(Дата)` | часть даты числом |
| `ДЕНЬНЕДЕЛИ` | `ДЕНЬНЕДЕЛИ(Дата)` | 1 — понедельник |
| `НАЧАЛОПЕРИОДА(д, Период)` | `НАЧАЛОПЕРИОДА(Дата, МЕСЯЦ)` | первое число месяца |
| `КОНЕЦПЕРИОДА(д, Период)` | `КОНЕЦПЕРИОДА(Дата, КВАРТАЛ)` | последняя секунда квартала |
| `ДОБАВИТЬКДАТЕ(д, Период, n)` | `ДОБАВИТЬКДАТЕ(Дата, ДЕНЬ, 7)` | дата плюс неделя |
| `РАЗНОСТЬДАТ(д1, д2, Период)` | `РАЗНОСТЬДАТ(Начало, Конец, ДЕНЬ)` | число дней |

```query
ВЫБРАТЬ
    НАЧАЛОПЕРИОДА(Дата, МЕСЯЦ) КАК Месяц,
    КОЛИЧЕСТВО(*) КАК Документов,
    СУММА(СуммаДокумента) КАК Сумма
ИЗ
    Документ.РеализацияТоваров
ГДЕ
    Проведен
СГРУППИРОВАТЬ ПО
    НАЧАЛОПЕРИОДА(Дата, МЕСЯЦ)
УПОРЯДОЧИТЬ ПО
    Месяц
```

Функция над полем в `ГДЕ` мешает СУБД использовать индекс: вместо `ГОД(Дата) = 2026` пиши `Дата МЕЖДУ &Начало И &Конец`.

## Строки

`ПОДСТРОКА(Строка, Начало, Длина)`, `ДЛИНАСТРОКИ`, `ВРЕГ`, `НРЕГ`, `СОКРЛП`, склейка через `+`. Сравнение строк не учитывает регистр и хвостовые пробелы.

## ВЫРАЗИТЬ — приведение типа

- сузить составной тип: `ВЫРАЗИТЬ(Регистратор КАК Документ.РеализацияТоваров)` — если тип другой, вернётся NULL;
- задать точность: `ВЫРАЗИТЬ(Сумма / Курс КАК Число(15, 2))`;
- ограничить длину: `ВЫРАЗИТЬ(Комментарий КАК Строка(100))`.

```query
ВЫБРАТЬ
    Период,
    ВЫРАЗИТЬ(Регистратор КАК Документ.РеализацияТоваров).Контрагент КАК Покупатель,
    Количество
ИЗ
    РегистрНакопления.ТоварыНаСкладах
ГДЕ
    Регистратор ССЫЛКА Документ.РеализацияТоваров
    И Номенклатура = ЗНАЧЕНИЕ(Справочник.Номенклатура.Ноутбук)
```
