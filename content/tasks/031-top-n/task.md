Аналог запроса `ВЫБРАТЬ ПЕРВЫЕ N Товар, СУММА(Сумма) … СГРУППИРОВАТЬ ПО Товар УПОРЯДОЧИТЬ ПО Сумма УБЫВ`.

`Продажи` — массив структур `{Товар, Сумма}` (товары повторяются). Верни массив названий товаров — не больше `Сколько` штук, от большей суммарной выручки к меньшей.

Удобнее всего через `ТаблицаЗначений`: `Свернуть("Товар", "Сумма")`, затем `Сортировать("Сумма Убыв")`.
