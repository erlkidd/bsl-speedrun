Из внешней системы пришёл JSON заказа:

```json
{"Номер": "A-1", "Товары": [{"Цена": 100, "Количество": 2}, {"Цена": 50, "Количество": 1}]}
```

Напиши `СуммаЗаказа(ТекстJSON)` — сумма `Цена * Количество` по всем товарам.
Чтение JSON из строки: `Чтение = Новый ЧтениеJSON; Чтение.УстановитьСтроку(Текст); Данные = ПрочитатьJSON(Чтение);` — получится Структура с массивом структур.
