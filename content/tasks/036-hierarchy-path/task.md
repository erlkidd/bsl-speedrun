У иерархического справочника каждый элемент знает своего родителя. `Родители` — `Соответствие`: имя элемента → имя родителя (у корневых элементов ключа нет).

Верни полный путь от корня до элемента через ` / `:

`ПутьВИерархии({Ноутбук: Электроника, Электроника: Товары}, "Ноутбук")` → `"Товары / Электроника / Ноутбук"`.
