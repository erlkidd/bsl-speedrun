Напиши `ТекстЗапроса(ИмяТаблицы, Поля)` — вернуть текст простого запроса одной строкой:

`ТекстЗапроса("Справочник.Склады", ["Код", "Наименование"])` → `"ВЫБРАТЬ Код, Наименование ИЗ Справочник.Склады"`.

Если массив полей пуст — выбирай всё: `ВЫБРАТЬ * ИЗ …`.

Так собирают только **имена** таблиц и полей. Значения отборов в текст не подставляют — для них есть параметры `&Имя`.
