Индекс в базе данных ищет по отсортированным значениям делением пополам — поэтому условие по индексируемому полю быстрое. Напиши `НайтиВОтсортированном(Числа, Искомое)`: массив отсортирован по возрастанию, верни индекс элемента (с нуля) или `-1`, если его нет.

Перебор всех элементов и `Массив.Найти()` запрещены.
